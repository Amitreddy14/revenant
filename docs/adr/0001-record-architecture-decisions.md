# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-03

## Context

The project is built in phases over weeks. Without a written trail, the reasons behind choices fade and get re-argued.

## Decision

Record every significant architectural decision as a short ADR in `docs/adr/`, numbered in order. Do not edit an accepted ADR's decision; supersede it with a new one.

## Consequences

- Reviewers can see why the system looks the way it does.
- Small overhead per decision, paid once.
